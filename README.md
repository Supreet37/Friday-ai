## 🤖 About

**F.R.I.D.A.Y.** is a voice-enabled AI desktop assistant built in Python, featuring a sleek web-based UI. Designed to handle everyday tasks through natural language commands, it brings a futuristic assistant experience right to your desktop — think Tony Stark, but for everyone.

---

## ✨ Features

- 🎙️ **Voice Recognition** — Speak commands naturally and get instant responses
- 🧠 **AI-Powered Responses** — Intelligent reply generation for queries and conversations
- 🌐 **Web Search** — Search the internet on command
- 🖥️ **Modern Web UI** — Beautiful, interactive frontend built with HTML, CSS & JavaScript
- ⚙️ **Modular Architecture** — Easily extensible with plug-and-play modules
- 🔧 **Configurable** — Customize assistant behavior via config files

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)
- A modern web browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ompreet-s/Friday-ai.git
   cd Friday-ai
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure the assistant**

   Edit the files inside the `config/` directory to set your preferences (API keys, assistant name, wake word, etc.).

4. **Run the assistant**
   ```bash
   cd backend
   python main.py
   ```

5. Open your browser and navigate to the address shown in the terminal to access the UI.

---

## 🛠️ Configuration

The `config/` directory contains settings to customize F.R.I.D.A.Y.'s behavior:

- Set your preferred **wake word**
- Add **API keys** for external services (weather, news, etc.)
- Toggle **modules** on or off

---

## 📦 Modules

F.R.I.D.A.Y. uses a modular system located in the `modules/` folder. Each module handles a specific capability (e.g., web search, system control, small talk). You can add new modules to extend functionality without touching core code.
